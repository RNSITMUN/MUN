📜 Google Apps Script Web App Code & Setup

⚡ 1-Minute Deployment Guide (for muntechnical@gmail.com)

  1. Log in to Google using muntechnical@gmail.com.
  2. Open script.google.com and click New project.
  3. Replace all existing code in Code.gs by clicking 📋 Copy Script to Clipboard below.
  4. Click Deploy → New deployment → Select type Web app (gear icon).
  5. Set Execute as: Me (muntechnical@gmail.com) and Who has access: Anyone.
  6. Click Deploy, grant permissions (Authorize access), and copy the Web App URL (ends in /exec).
  7. Paste the URL into the Webhook URL field in the Mail Templates tab and click 💾 Save Webhook URL.
